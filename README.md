# Roman and Rubin Cosmology Analysis

Self-directed implementation of NASA Nancy Grace Roman Space Telescope and Vera C. Rubin Observatory public science pipelines (DP0) in Python. Code base developed using public tutorials, dataset specifications, and lecture materials distributed by Caltech's Fornax Roman science working group.


## Prerequisites and Installation

List of the required software environment, dependencies, and setup commands.

- Programming language: Python 3.10
- Core libraries: AstroPy, Pandas, Matplotlib
- Mission specific tools:

```bash
  git clone https://github.com/richapurba/roman-and-rubin-analysis/
  cd roman-and-rubin-analysis
  pip install -r requirements.txt
```
